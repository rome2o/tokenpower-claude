# Contributing

Issues and pull requests are welcome.

- Open an issue first for anything larger than a small fix.
- Each mod lives in `plugins/<name>/`. Keep changes inside one mod where you can.
- Run `claude plugin validate .` from the repo root before opening a pull request.
- Do not commit secrets, client names or personal data.
- Use plain sentences in docs. No em dashes.

By contributing you agree your work is released under the MIT license in `LICENSE`.
